## Deviations

1. **Scaffold smoke test added.** The task allowed empty test suites, but Bun 1.4.5 returns exit 1
   when no tests match, which would fail `bun test` and `bun run verify`. Instead of weakening the
   gate, `tests/integration/scaffold.test.ts` asserts four scaffold invariants. It contains no
   compiler logic.
2. **Biome ignores protected files.** `opencode.jsonc` and `AGENTS.md` are excluded because Biome
   wanted to reformat `opencode.jsonc` and it is outside the owned scope.
3. **Index READMEs in docs directories.** `docs/{grammar,cascade,configuration}` would otherwise be
   empty; each has a short pointer README, within the allowed directories.
4. **Package exports point at `dist`.** Package manifests declare `dist` entry points while the
   source stubs are intentionally empty. No package is consumed yet; build/packaging is scheduled
   for later phases.
